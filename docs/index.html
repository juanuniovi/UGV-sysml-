¿Cómo funciona?

Las tareas del proyecto se leen en directo desde los GitHub Issues del repositorio (juanuniovi/UGV-sysml-). De este modo, cualquier tarea asignada aparece automáticamente en el navegador de cualquier compañero al abrir la web.

Si añades tu token, podrás crear y cerrar tareas con un solo clic desde la web. Se almacena únicamente en tu navegador (localStorage), nunca en el repositorio.
